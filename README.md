環境初始化：於左側面板輸入廠區 X/Y 總長與柱位參數，點擊「設定廠區」。

新增設備：輸入機台名稱與尺寸 (cm)，點擊「加入機台」。

規劃擺放：

手動模式：直接用滑鼠拖動機台。觀察對齊線與自動生成的距離標註。

自動模式：點擊「智能自動排列」，系統將按預留走道標準自動填滿安全空位。

合規檢查：確保畫面上機台皆為 半透明藍色。若機台變 紅色，請根據紅色虛線指引挪動位置，直到警告消失。

存檔輸出：確認無誤後，點擊「導出 Layout PNG」存檔。

建議瀏覽器：Google Chrome, Microsoft Edge (不支援 IE)。

核心單位：全系統統一使用 公分 (cm)。

繪圖引擎：Konva.js 2D Canvas Engine。

網路需求：初次開啟需連網載入外掛庫；若需離線使用請洽開發者提供離線包。

Tip: 如果發現柱位有變動，可以使用「僅更新柱子」按鈕，這會重新繪製柱網但保留你已經辛苦擺好的機台位置。
